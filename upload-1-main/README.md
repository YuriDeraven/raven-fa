# Raven Football Academy website

Static site for GitHub Pages (no build step). Live at https://yurideraven.github.io/raven-fa/

- `index.html`: page structure
- `css/style.css`: styles
- `js/data.js`: ALL content (players, matches, schedule, fees, contacts). Edit here.
- `js/hero3d.js`: 3D hero football
- `js/main.js`: interactions
- `assets/`: logos and photos (relative paths only)

Update placeholders marked `PLACEHOLDER` in `js/data.js` before launch.
